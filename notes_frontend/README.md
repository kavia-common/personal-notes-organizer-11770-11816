# Notes Frontend (Qwik) ⚡️

A minimalistic, responsive notes app built with Qwik + Qwik City.

- Create, edit, delete notes
- Sidebar list with search
- LocalStorage persistence
- Light theme using palette:
  - primary: #4f46e5
  - secondary: #6d28d9
  - accent: #f59e42

## Development

- npm start
- Open the printed URL (or http://localhost:3000)

## Usage

- Click “+ New” to create a note
- Select a note from the list to edit
- Title/content auto-save on blur, or click Save
- Use Delete to remove a note
- Search filters by title and content

Built from the Qwik starter. See Qwik docs for more details:
- https://qwik.dev/
- https://qwik.dev/qwikcity/overview/
